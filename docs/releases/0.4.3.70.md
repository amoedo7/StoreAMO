# StoreAMO 0.4.3.70

## Administración de aplicaciones instaladas

- `Desinstalar` entrega el package de la app al desinstalador oficial de Android.
- StoreAMO intenta `ACTION_UNINSTALL_PACKAGE` y conserva `ACTION_DELETE` como ruta de compatibilidad.
- Si Android cancela, bloquea o devuelve el flujo sin haber eliminado la app, StoreAMO abre automáticamente `Info. de la aplicación` mediante `ACTION_APPLICATION_DETAILS_SETTINGS`.
- Cada aplicación instalada muestra además un botón `ⓘ` junto a `Desinstalar` para abrir directamente `Info. de la aplicación`.
- Si un fabricante no expone la pantalla específica del paquete, se abre la administración general de aplicaciones como último respaldo.
- StoreAMO no intenta desinstalarse a sí mismo desde este flujo.

La eliminación efectiva sigue perteneciendo a Android: StoreAMO nunca borra silenciosamente un paquete ni evita la confirmación del sistema.
