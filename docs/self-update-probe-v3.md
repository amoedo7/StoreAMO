# StoreAMO V3 · self-update probe

Este archivo existe únicamente para forzar una compilación posterior a la primera build de StoreAMO V3.

Objetivo de prueba:

1. instalar una build V3 anterior;
2. abrir **Actualizaciones**;
3. comprobar que StoreAMO detecta una Release V3 más nueva desde GitHub;
4. descargarla, verificar SHA-256 y actualizar sin desinstalar.

No contiene secretos ni configuración de producción.
