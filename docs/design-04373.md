# StoreAMO 0.4.3.73 — Solar Calm

Dirección de diseño: bajar ruido, subir jerarquía y hacer que la identidad de StoreAMO se sienta propia sin separarse de DesarrollAMO.

Principios:
- ámbar solar = foco, acción y estado activo;
- cian = información y tecnología;
- rosa = creación;
- violeta queda como acento secundario, no dominante;
- superficies más profundas y limpias;
- esquinas y controles coherentes;
- el icono conserva las cuatro piezas, ahora abrazadas por un halo solar.

No se agregan números ficticios ni actividad decorativa.
