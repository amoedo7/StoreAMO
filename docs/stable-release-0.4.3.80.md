# StoreAMO 0.4.3.80 stable channel

This release aligns the Android self-update channel with the public StoreAMO manifest: GitHub Releases now publishes the current StoreAMO build as a stable release instead of prerelease-only. This allows `/releases/latest`, StoreAMO-Catalog discovery, external installers, and the in-app self-updater to resolve the same canonical APK.
